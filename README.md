## ❗️ Troubleshooting

| Problem | Solution |
| :--- | :--- |
| **Link not recognized** | Make sure you copy the full URL from the platform (include `https://`). |
| **Download stuck at 0%** | Check your internet connection or switch to a different DNS. |
| **No audio in file** | Re-download using FLAC format or update the `ffmpeg_core.dll`. |
| **Wrong metadata** | Enable "Force Metadata Refresh" in the Settings tab. |
| **Antivirus flagged** | Add the installation folder to your antivirus exclusion list. |
| **App won't open** | Install **Microsoft Visual C++ 2022** and **.NET Framework 4.8**. |
